Interactive Topics Quiz

Description
    This is an interactive text-only quiz built with HTML, CSS, and JavaScript. It allows users to answer multiple-choice questions, see hints, track their time, and get results at the end.

✨ Features
- 5 questions across Geography, Science, Technology, Sports, and Entertainment.
- Timer to limit quiz duration (adjustable).
- Hints for each question.
- Score calculation and visual feedback

🔧 Technologies Used
- `index.html` — HTML structure for the quiz.
- `style.css` — Styling for quiz interface.
- `script.js` — Quiz functionality (dynamic questions, timer, scoring).
- `README.md` — Project description.

🧠 How to run
1. Open `index.html` in a browser.
2. Set the quiz duration if needed.
3. Click **Start Quiz**.
4. Select answers for each question.
5. Click **Submit Answers** to see your score.
6. Use **Restart Quiz** to try again.
